SYSTEM NOTES / LIMITATIONS

AI4I 2020 is a synthetic predictive-maintenance dataset.

Prediction quality depends on data quality and the test split.

This project predicts failure class, not exact failure time.

No true Remaining Useful Life (RUL) target is predicted.

Real machines may expose additional sensor variables.

Cluster labels are exploratory groups and do not equal the known failure label.
